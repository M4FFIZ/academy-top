# Где захостить проект «Академия ТОП» для защиты диплома

**Для кого:** инструкция «для чайника», без опыта в серверах.  
**Цель:** чтобы проект открывался по ссылке в браузере на защите диплома.  
**Бюджет:** от 0 ₽ (с ограничениями) до ~500 ₽/мес.

---

## 1. Что вообще нужно разместить?

Ваш проект — это не обычный сайт на WordPress. Внутри **три части**:

| Часть | Что это | Аналогия |
|-------|---------|----------|
| **Сайт** (Next.js) | То, что видит пользователь в браузере | Витрина магазина |
| **API** (NestJS) | Сервер: логин, оценки, расписание | Склад и касса |
| **База данных** | Хранит учеников, сообщения, оценки | Тетрадь с записями |
| **Чат** (WebSocket) | Сообщения в реальном времени | Телефон между пользователями |

**Обычный хостинг Beget «Сайты» (PHP)** — **не подходит**.  
Там нельзя нормально запустить Node.js и WebSocket.

**Подходит:** облачные платформы с Node.js или VPS (виртуальный сервер).

## 3. Моя рекомендация для защиты диплома

### 🥇 Основной вариант: **Render.com** (бесплатно или ~$7/мес)

**Почему:**
- Регистрация через GitHub — 10 минут
- Не нужно знать Linux

- Поддерживает Node.js и WebSocket
- Для диплома хватает с головой

**План:**
1. Залить проект на **GitHub**
2. На Render создать: **PostgreSQL** + **Web Service (API)** + **Web Service (сайт)**
3. Получить ссылку вида `https://academy-top.onrender.com`

### 🥈 Если готовы платить ~500 ₽/мес: **Railway.app**

- Быстрее, не засыпает
- Проще один раз настроить — работает стабильнее на защите

Держите на ноутбуке:
```powershell
cd C:\Projects\academiya
npm run dev
```
И открывайте `http://localhost:3000` — если облако подведёт, покажете локально.  
**Это нормально для диплома**, многие так делают.

## 4. Подготовка проекта (один раз)

### Шаг 4.1. Аккаунт GitHub

1. Зайдите на https://github.com
2. Зарегистрируйтесь
3. Создайте репозиторий `academy-top` (приватный или публичный)
4. Загрузите проект из `C:\Projects\academiya`

**Через Git (если установлен):**
```powershell
cd C:\Projects\academiya
git init
git add .
git commit -m "Диплом: личный кабинет Академия ТОП"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/academy-top.git
git push -u origin main
```

**Без Git:** на GitHub → «Add file» → «Upload files» → перетащите папку (без `node_modules`!).

> ⚠️ Не загружайте `node_modules`, `.next`, `dev.db` — они большие и не нужны.

Добавьте в `.gitignore` (уже есть):
```
node_modules
.next
apps/api/prisma/dev.db
.env
```

---

### Шаг 4.2. Переключить базу на PostgreSQL (для облака)

Откройте `apps/api/prisma/schema.prisma`, найдите:

```prisma
datasource db {
  provider = "sqlite"
  url      = env("DATABASE_URL")
}
```

Замените на:

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

Сохраните файл. На Render PostgreSQL выдаст готовую строку подключения.

## 5. Пошаговая инструкция: Render.com

### Шаг 5.1. Регистрация

1. https://render.com → **Get Started**
2. Войти через **GitHub**
3. Разрешить доступ к репозиторию

---

### Шаг 5.2. Создать базу данных

1. Dashboard → **New +** → **PostgreSQL**
2. Name: `academy-db`
3. Plan: **Free** (для диплома достаточно)
4. Create Database
5. Скопируйте **Internal Database URL** (понадобится для API)

---

### Шаг 5.3. Задеплоить API (бэкенд)

1. **New +** → **Web Service**
2. Connect репозиторий `academy-top`
3. Настройки:

| Поле | Значение |
|------|----------|
| Name | `academy-api` |
| Root Directory | `apps/api` |
| Runtime | Node |
| Build Command | `npm install && npx prisma generate && npm run build` |
| Start Command | `npx prisma db push && npx ts-node prisma/seed.ts && node dist/main.js` |

4. **Environment Variables** (переменные окружения):

| Key | Value |
|-----|-------|
| `DATABASE_URL` | вставьте Internal Database URL из шага 5.2 |
| `JWT_SECRET` | любая длинная строка, например `diplom2026secretkey32chars!!` |
| `JWT_EXPIRES_IN` | `7d` |
| `PORT` | `3001` |
| `CORS_ORIGIN` | пока `*` (потом замените на URL сайта) |

5. **Create Web Service**
6. Дождитесь зелёного статуса **Live**
7. Скопируйте URL API, например: `https://academy-api.onrender.com`

Проверка: откройте в браузере  
`https://academy-api.onrender.com/v1/auth/login` — должна быть ошибка метода (это нормально, API живой).

---

### Шаг 5.4. Задеплоить сайт (фронтенд)

1. **New +** → **Web Service**
2. Тот же репозиторий
3. Настройки:

| Поле | Значение |
|------|----------|
| Name | `academy-web` |
| Root Directory | `apps/web` |
| Build Command | `npm install && npm run build` |
| Start Command | `npm run start` |

4. **Environment Variables:**

| Key | Value |
|-----|-------|
| `NEXT_PUBLIC_API_URL` | `https://academy-api.onrender.com/v1` |
| `NEXT_PUBLIC_WS_URL` | `https://academy-api.onrender.com` |

5. **Create Web Service**

6. Когда сайт задеплоится — скопируйте URL, например:  
   `https://academy-web.onrender.com`

---

### Шаг 5.5. Обновить CORS на API

1. Render → `academy-api` → **Environment**
2. Измените `CORS_ORIGIN` на URL сайта:
   ```
   https://academy-web.onrender.com
   ```
3. Сохраните — сервис перезапустится

---

### Шаг 5.6. Проверка

1. Откройте `https://academy-web.onrender.com`
2. Войдите: `student@top.ru` / `password123`
3. Проверьте: расписание, оценки, чат

**На бесплатном Render:** если долго не заходили — первое открытие 30–60 сек.  
За 10 минут до защиты откройте сайт сами, чтобы «разбудить».

## 10. Частые проблемы

| Проблема | Решение |
|----------|---------|
| Сайт долго грузится | Бесплатный Render «спал» — подождите 1 мин |
| «Network Error» при входе | Проверьте `NEXT_PUBLIC_API_URL` на фронте |
| Чат не работает | `NEXT_PUBLIC_WS_URL` должен быть URL API без `/v1` |
| CORS error в консоли | `CORS_ORIGIN` на API = точный URL сайта |
| База пустая | Перезапустите API (seed выполняется при старте) |
| Build failed | Смотрите Logs на Render → исправьте ошибку |
